# 工具脚本

按用途分三类。

## 手机摄像头

| 脚本 | 作用 |
|---|---|
| `phone_watch.py` | 一键：等插线 → 切 tcpip → 提示拔线 → 连 WiFi → 配转发 |
| `usb_cam_wifi.py` | 上面那个的详细版，可单步执行 |
| `usb_cam.py` | 纯 USB 转发（不切 WiFi 时用） |
| `show_cam_url.py` | 看当前该用哪个地址 |
| `watch_serial.py` | 盯串口，ESP32 插上就报 |

`phone_watch.py` 要插一次线，是为了把 adb 从 USB 切到网络模式。
切完就能拔，USB 口还给 ESP32。

## 画面质量检查

| 脚本 | 作用 |
|---|---|
| `check_frame.py` | 看尺寸、格式、信息密度 |
| `frame_light.py` | 看亮度分布 |
| `frame_sharp.py` | 算清晰度（拉普拉斯方差） |
| `see_frame.py` | 让 AI 描述当前画面 |

`frame_light.py` 的重点是**能区分「环境暗」和「摄像头被挂起」**：

| | 环境暗 | 摄像头挂起 |
|---|---|---|
| 平均亮度 | 3~15（有噪点） | **完美的 0** |
| 该做什么 | 开灯 | 解锁手机 |

两个在模型眼里都是黑的，但该做的事完全不同。

`frame_sharp.py` 的判据：

| 拉普拉斯方差 | 判定 |
|---|---|
| < 50 | 很糊（失焦 / 抖动 / 镜头脏） |
| 50~150 | 偏软 |
| 150~500 | 正常 |
| > 500 | 很锐利 |
